# Mudarris Akademiyasi — landing page

Static landing page for **Mudarris Arab tili Akademiyasi** (Tashkent, Uzbekistan).

Content sourced from the academy's public [Telegram channel](https://t.me/s/mudarris_akademiyasi)
and [Instagram profile](https://www.instagram.com/mudarris_akademiyasi/).

## Structure

- `public/index.html` — the page (Uzbek, Latin script)
- `public/styles.css` — styles; brand blue `#2A5298` taken from the academy logo
- `public/script.js` — sticky nav, mobile menu, scroll reveal, stat count-up
- `public/assets/logo.jpg` — academy logo

No build step. Deployed on Vercel as a static site.

## Local preview

```bash
npx serve public
```
